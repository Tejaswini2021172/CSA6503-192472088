# AI Text Summarizer

## Description
This application compares Extractive and Abstractive Text Summarization.

## Features
- Paste Text
- Upload PDF
- Upload TXT
- Extractive Summarization (LSA - Sumy)
- Abstractive Summarization (Google Gemini 3.6 Flash)
- Download summaries
- Statistics
- Comparison table

## Requirements
pip install -r requirements.txt

## Run

streamlit run app.py
